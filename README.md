# MyGolf

골프 라운드 기록·분석 웹. [golf-round-web](https://github.com/supok00/golf-round-web)을 바탕으로 기능을 넓힌 별도 소스입니다.
골프라운지(golflounge.co.kr) 개인 통계 화면을 참고해 보완했습니다.

**주소**: https://supok00.github.io/mygolf/

## golf-round-web 대비 추가 기능
- **공통 필터**: 기간(전체·최근 90일·이번 달·지난 달·연도), 골프장 검색, 18홀만 — 대시보드·목록·통계·인사이트·홀파·상세 분석에 같은 조건 적용
- **스코어 유형 카드**: 홀인원·알바트로스·이글·버디·파·보기·더블·트리플+ 횟수, 누르면 그 스코어가 나온 라운드 목록
- **평균·안정성**: 표준편차, 최고·최저, 최근 10라운드 평균
- **베스트 TOP 10**
- **타수 추이 자동 집계**: 기간 1년 이하 월별, 3년 이하 분기별, 그 이상 연도별 (평균 타수 + 라운드 수). 연도 선택 시 월별
- **라운드 인사이트**: 올해 누적·평균·베스트, 첫 기록 후 일수, 평균 라운드 간격, 주말 비중, 요일별, 오전/오후, 최근 90일
- **자주 가는 골프장**: 방문 순위, 최근 방문 점수, 이름을 누르면 그 골프장만 필터
- **탭별 설명**: 각 화면이 무엇을 기준으로 집계했는지
- **스마트스코어 붙여넣기 등록**: 네이버 스마트스코어 라운드 텍스트를 붙여 넣으면 골프장·코스·날짜·티오프·홀별 Par/Score를 읽어 등록 (여러 라운드 한 번에, 합계 검증, 기존 골프장명 자동 맞춤, 중복 제외)

## 데이터
- 라운드는 이 저장소의 `data/rounds.json`에 저장하고, **저장할 때 golf-round-web 저장소의 같은 파일에도 같은 변경을 적용해 동기화**합니다. golf-round-web에서 저장해도 이쪽에 반영됩니다.
- 저장에는 **mygolf와 golf-round-web 두 저장소 모두**에 Contents 읽기/쓰기 권한이 있는 fine-grained 토큰이 필요합니다. 어긋나면 설정 → 동기화에서 확인하고 맞출 수 있습니다. 같은 기기에서 golf-round-web에 넣어 둔 토큰이 있으면 처음 열 때 가져옵니다.
